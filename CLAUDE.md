# pro-storefront

See `CONTEXT.md` in this folder for full architecture, auth flows, known
issues, and Netlify function reference — it's the maintained source of truth
for this project and is kept up to date across sessions. Read it first.

One-line summary: "TheGrint Shop PRO" — a members-only storefront gated
behind TheGrint PRO-membership OAuth login, backed by Netlify Functions
talking to both TheGrint (auth/membership) and Shopify (catalog/checkout).
Deployed at `https://pro-storefront.netlify.app`.
